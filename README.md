# 찹찹 (ChopChop)

지금 당장 시작해서 한 시간 안에 끝낼 일을 잘게 잘라 주는 웹 프로토타입.

**데모: https://moonsujin0309.github.io/chopchop/**

빌드 도구도 의존성도 없습니다. `index.html` 하나가 전부이고, 데이터는 브라우저 localStorage에만 남습니다.

## 어떻게 쓰나

1. `+` 를 눌러 할 일을 적습니다 — 예: `잠잘 준비하기`
2. 생각 말풍선이 갈라지며 **후보**가 흩어져 나옵니다
3. 해당되는 것만 고릅니다. 없으면 `+ 직접 추가`, 부족하면 `다른 찹 생성`(최대 2번)
4. `다 골랐어요` → 휠로 **몇 분 안에 끝낼지** 정합니다
5. `집중 시작` → 세션 타이머가 돌고, `✓` 로 찹을 하나씩 지웁니다

찹마다 시간을 정하지 않습니다. 사용자가 아는 값은 "이걸 30분 안에 끝내겠다" 하나뿐이라, 그것만 받습니다.

## AI 분해

**마이 → 설정 → AI 분해**에 Anthropic API 키를 넣으면 실제 모델이 후보를 만듭니다.
비워두면 내장 사전으로 동작합니다.

> **키는 이 기기의 localStorage에만 저장되고, 코드에는 들어 있지 않습니다.**
> 서버가 없어 브라우저에서 API를 직접 호출하는 구조입니다. 프로토타입 한정이며,
> 실서비스에서는 백엔드 프록시를 두고 키를 서버에 보관해야 합니다.
> 공용 PC에서는 키를 넣지 마세요.
